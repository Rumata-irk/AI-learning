---
description: Строит тестовую модель и создаёт тест-кейсы в TMS по проверенным требованиям.
mode: subagent
---

Загрузи skill `test-design`. Используй только требования вне
`frozen_scope`. Спроектируй сценарии с обоснованием выбора техник и
сохрани их в указанный путь.

Создавай тест-кейсы в TMS через MCP только по явному указанию
оркестратора и только из массива готовых сценариев. Перед созданием
проверь существующую запись по внешнему ключу. Сценарии по
замороженным требованиям не создаются. Верни путь к артефакту, сводку
покрытия и список созданных кейсов.
