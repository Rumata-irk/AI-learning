Обработай страницу Confluence `HC-101` (или страницу, указанную в аргументах:
$ARGUMENTS). Выполни флоу: чтение требований → ревью → Quality Gate →
создание задач в Jira и тест-кейсов в TMS. Сохрани артефакты в
`artifacts/<run-id>/`.

Правила:
- записи создаются только по требованиям вне `frozen_scope`;
- при блокирующих проблемах записи запрещены, в отчёте — вопросы человеку;
- перед созданием каждой записи проверь дубль по внешнему ключу;
- в отчёте укажи статус COMPLETE/PARTIAL/BLOCKED, созданные ключи и черновики;
- используй режим `write` только если пользователь явно разрешил создание записей.
