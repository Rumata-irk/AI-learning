# Анализ требований

Для каждого требования укажи REQ-ID, формулировку и цитату источника. Выдели правила, зависимости, риски, противоречия и недостающие данные. Не придумывай критерии приёмки. Для каждой блокирующей проблемы укажи затронутые требования и зависимые от них; сформируй замороженную область и конкретный вопрос человеку.

Статус `ready` — нет блокирующих проблем; `ready_partial` — область проблем и все зависимости определены, остаются независимые проверяемые требования; `blocked` — область или зависимости неизвестны либо независимых требований не осталось. При `ready_partial` не разрешай конфликт за человека. Вывод: таблица требований, таблица проблем и зависимостей, замороженная область, вопросы и статус.
