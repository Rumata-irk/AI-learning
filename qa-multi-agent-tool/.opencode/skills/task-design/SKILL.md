# Проектирование задач

Используй только требования вне замороженной области. Для каждой задачи укажи TASK-ID, цель, описание, REQ-ID, зависимости, проверяемые критерии приёмки и статус. Не подменяй критерий формулировкой «соответствует REQ-n». Если конкретный критерий невозможно вывести из исходника, зафиксируй пробел, сформулируй вопрос и назначь `pending_clarification`; иначе `ready`. Не выдумывай реализацию и не создавай записи в Jira. Добавь трассировку REQ → TASK и причины пропусков.
