# Тестовая модель

Используй требования вне замороженной области. Для каждого сценария укажи TC-ID, REQ-ID, тип, предусловия, данные, шаги, проверяемый ожидаемый результат и статус готовности. Рассмотри позитивные, негативные и граничные проверки, но применяй каждый тип только когда он обоснован. Неприменимость укажи с причиной; нехватку условий или ожидаемого результата обозначь GAP и сформулируй вопрос. Не создавай проверки ради заполнения матрицы и не придумывай ожидаемое поведение. Добавь матрицу REQ → TC и непокрытые условия.
