## Текст требований (дословно, восстановлено 2026-11-16: исправлено имя метрики по ответу MCP)

Healthchecker получает значение метрики marketplace_api_health_status из Prometheus.
Метрика запрашивается у Prometheus HTTP API методом GET по эндпоинту /api/v1/query, адрес задаётся в конфигурации prometheus.url, параметр query равен marketplace_api_health_status.
Успешным получением считается HTTP-ответ 200, в теле которого есть результат с непустым значением метрики.
Интервал опроса составляет 60 секунд и отсчитывается от завершения предыдущего опроса.
При успешном получении сервис сохраняет последнее значение метрики в памяти процесса.
Сохранённое значение доступно в ответе GET /healthchecker в поле last_metric_value.
Поведение при недоступности Prometheus не определено.
