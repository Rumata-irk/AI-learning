### T-001

- `local_id`: T-001
- `title`: Запрос метрики `marketplace_api_health_status` к Prometheus HTTP API
- `description`:
  Реализовать запрос значения метрики к Prometheus HTTP API в соответствии с
  `REQ-002`: метод GET, эндпоинт `/api/v1/query`, адрес берётся из конфигурации
  `prometheus.url`, параметр `query` равен `marketplace_api_health_status`.

  Критерии приёмки (наблюдаемы снаружи):
  1. Исходящий запрос метрики выполняется методом HTTP GET.
  2. Путь исходящего запроса — `/api/v1/query`.
  3. Хост/схема исходящего запроса совпадают с адресом, заданным в
     конфигурации `prometheus.url` (при изменении значения конфигурации
     меняется адрес запроса без изменения кода).
  4. Параметр `query` исходящего запроса равен строке `marketplace_api_health_status`.

  - `req_ids`: `REQ-002`
  - `depends_on`: —

  Вне области задачи (не проверяется здесь): обработка ответа, критерий
  успеха/неуспеха, сохранение значения, поведение при ошибке.

### T-002

- `local_id`: T-002
- `title`: Период опроса 60 секунд от завершения предыдущего опроса
- `description`:
  Реализовать периодическое выполнение запроса метрики в соответствии с
  `REQ-004`: интервал опроса — 60 секунд, отсчитывается от завершения
  предыдущего опроса (не от его начала).

  Критерии приёмки (наблюдаемы снаружи):
  1. Для двух последовательных опросов разница между моментом завершения
     предыдущего опроса и моментом начала следующего составляет 60 секунд
     (в пределах допустимого отклонения таймера; величина отклонения в
     источнике не задана — не задаётся и здесь).
  2. Если предыдущий опрос занял заметное время, следующий опрос НЕ стартует
     через 60 секунд после старта предыдущего: старт отсчитывается от
     завершения.

  - `req_ids`: `REQ-004`
  - `depends_on`: T-001 (интервал задаёт частоту опроса, т.е. выполнения запроса из T-001)
  - `pending_clarification`: момент первого опроса после старта сервиса
    (P-004, minor — не блокирует проектирование интервала). Критерий приёмки
    ограничен периодом между опросами; запуск цикла — см. draft D-003.
