# Проверка локального MCP

- Команда: `python -m unittest discover -s tests -v`.
- Результат: 1 интеграционный тест пройден; MCP stdio, чтение демонстрационной страницы, запись и поиск локальных объектов, повтор с тем же ключом и ошибка при конфликте данных проверены.
- Полный запуск четырёх агентов OpenCode не выполнен: команда `opencode` недоступна в PATH в текущем окружении. Артефакты работы агентов и создания сущностей в реальных Jira/Qase не заявляются как полученные.
